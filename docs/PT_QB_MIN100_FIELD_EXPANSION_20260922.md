## Authoring method
Each new item is derived only from an existing Q1-Q2000 item in the same field that already has one accepted answer, five complete choices, five complete choice explanations, and an existing Knowledge Node tag. The learner judges why a specific original choice is correct or inappropriate using the five existing rationales as answer options. This avoids inventing unsupported medical facts while changing the demand from answer recognition to rationale discrimination.
