# SEO Foundation Done Criteria

- `/site` title and description explicitly target physical therapist national exam preparation.
- `/site` has canonical and Open Graph URL metadata.
- `/site` has structured data for the site/application.
- `/robots.txt` is available and points to `/sitemap.xml`.
- `/sitemap.xml` lists the canonical public site and FAQ page only.
- Preview/source boundaries return `X-Robots-Tag: noindex, nofollow, noarchive`.
- Approved PC/mobile visual content is not redesigned.
- Dedicated tests and repository CI pass.
- Production deploy becomes live without visible regression.
